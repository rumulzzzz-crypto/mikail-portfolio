# Портфолио Микаила Дадашова

**Опубликованная версия:** https://rumulzzzz-crypto.github.io/mikail-portfolio/

Статический сайт без сборки и внешних зависимостей. Работает как локальный `index.html` и на любом обычном статическом хостинге.

## Запуск

Откройте `index.html` в браузере. Для проверки в режиме локального сервера:

```powershell
py -3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Публикация через GitHub Pages

1. Создайте пустой публичный репозиторий GitHub.
2. Добавьте его как `origin` и отправьте ветку `main`:

   ```powershell
   git remote add origin https://github.com/USERNAME/REPOSITORY.git
   git push -u origin main
   ```

3. В настройках репозитория откройте **Settings → Pages → Build and deployment** и выберите **GitHub Actions**. Файл `.github/workflows/pages.yml` развернёт сайт после каждого push в `main`.

Публичный адрес указан выше и в разделе **Settings → Pages**.

## Содержимое

- `index.html` — разметка и метаданные.
- `styles.css` — адаптивное оформление.
- `app.js` — 11 выступлений, фильтры, модальное окно и контакты.
- `assets/` — три фотографии и превью для социальных сетей.

Для изменения контактов отредактируйте `CONTACTS` в `app.js`. Данные выступлений находятся в массиве `CLIPS` там же. Ссылки открывают видео на исходных площадках; воспроизведение на этих площадках зависит от их доступности и правил.
